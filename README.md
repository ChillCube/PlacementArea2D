# PlacementArea2D

a node that lets you define areas to place objects (like cards) onto the screen

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/PlacementArea2D.git
```

## Documentation
https://github.com/ChillCube/PlacementArea2D/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon PlacementArea2D
```
